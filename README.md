# Python Data Analysis Project

## 📌 About the Project
This project performs data analysis on sales data using Python.
The analysis helps identify sales trends, product performance,
and useful business insights.

## 🛠️ Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📂 Dataset
The project uses `Sales_Data.csv` as the dataset for analysis.

## 📊 Analysis Performed
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Sales Analysis
- Product-wise Analysis
- Category-wise Analysis
- City-wise Analysis
- Data Visualization
- Identification of trends and patterns

## 📈 Visualizations
The project contains different charts and graphs created using
Matplotlib and Seaborn.

## 📁 Project Files
- `PYTHON DATA_ANALYSIS PROJECT (2).ipynb` — Jupyter Notebook
- `Sales_Data.csv` — Sales dataset
- `README.md` — Project documentation

## 🎯 Objective
To analyze sales data and extract meaningful insights that can
help understand sales performance and trends.
